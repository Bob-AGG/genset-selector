# 文档目录

本目录存放**选型逻辑与数据规范的设计文档**，随代码一起版本管理。改选型逻辑前先读这里。

## 文档清单

| 文件 | 内容 | 什么时候看 |
|---|---|---|
| `底层逻辑.md` | **系统怎么搭的**：架构、24 字段数据模板、前端机制、函数索引、部署维护规范 | 要改数据结构/前端代码时 |
| `选型逻辑详解.md` | **怎么选电机**：定口径 → 定折损 → 定匹配，含完整实例演算、规则速查卡、常见误判 | 要改选型算法/给销售讲解时 |
| `用户操作逻辑.md` | 用户心智模型 vs 现有表单顺序的断层分析，4 个待拍板决策点 A/B/C/D | 讨论交互改版时 |
| `降额数据收集速查.md` | IP44 / C5 降额系数向厂家索要数据的清单 | 收集降额数据时 |

同名 `.docx` 为方便外发的 Word 版，内容与 `.md` 一致。

## 维护约定

改选型逻辑时请同步更新对应文档，尤其是：

1. **字段模板变化** → 更新 `底层逻辑.md` 第二章的字段表
2. **修正系数变化** → 更新 `底层逻辑.md` 第三章 + `选型逻辑详解.md` 第二章
3. **取功率口径变化** → 更新 `选型逻辑详解.md` 第一章的规则表
