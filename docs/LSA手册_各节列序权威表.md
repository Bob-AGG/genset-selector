## 关键结论：三种列序

手册里存在 **3 种不同的列序**，必须逐节区分：

| 列序类型 | 顺序 | 出现在 |
|---|---|---|
| **甲** | D星形 → F三角形 → A并联星形 | 8.1, 8.3, 9.1, 9.3 |
| **乙** | D星形 → A并联星形 → F三角形 | 8.5, 9.2, 9.4, 9.5 |
| **丙** | 仅 D星形（单列） | 8.2, 8.6, 8.7, 8.8, 8.9, 9.6, 9.7 |

## 50Hz（第8章）

### 8.1 标准6号绕组 — 列序【甲】
表尾原文：`D 星形(12线或6线)` / `A 并联星形(12线)` / `F 三角形(12线或6线)`
电压行：`380-400-415V` / `190-200-208V` / `220-230-240V`

⚠️ 注意：表尾列名行的写法是 D/A/F，但**电压行顺序是 380V / 190V / 220V**，即：
**D(380V) → A(190V) → F(220V)**

| 组 | 电压组1 | 电压组2 | 电压组3 | 功率列位置 |
|---|---|---|---|---|
| D 星形 | 380V | 400V | 415V | 第1组 |
| A 并联星形 | 190V | 200V | 208V | 第2组 |
| F 三角形 | 220V | 230V | 240V | 第3组 |

→ 本库拆成 `6-380`(370/220/190)、`6-400`、`6-415` 三 code ✅

### 8.2 标准6号绕组 220V/440V — 列序【丙】
表尾原文：`D 星形(12线或6线)` / `A 并联星形(12线)`
电压：`440V` / `220V`

| 接法 | 电压 |
|---|---|
| D 星形 Y | 440V |
| A 并联星形 YY | 220V |

→ 本库 code `6-230`（只有一个Y），**缺 YY/220V 行** ⚠️

### 8.3 标准6号绕组(可选12出线) — 列序【甲】
表头原文：`D 星形(12线或6线)` / `A 并联星形(12线)` / `F* 三角形(12线或6线)`
电压：`380-400-415V` / `190-200-208V` / `220-230-240V`

同上：D(380V) → A(190V) → F(220V)

### 8.4 标准6号绕组(可选12出线) 220V/440V — 列序【丙】
`D 星形` 440V / `A 并联星形` 220V

### 8.5 特殊7号绕组 — 列序【乙】
表尾原文：`D 星形(12线或6线)` / `A 并联星形(12线)` / `F 三角形(12线或6线)`
电压行：`415-440V` / `208-220V` / `240-254V`

| 组 | 电压组1 | 电压组2 | 功率列位置 |
|---|---|---|---|
| D 星形 Y | 415V | 440V | 第1组（kVA:208V,240V,415V） |
| A 并联星形 YY | 208V | 220V | 第2组 |
| F 三角形 Δ | 240V | 254V | 第3组 |

⚠️ **原库写成 Y/Δ/YY，应为 Y/YY/Δ** ❌

### 8.6 特殊9号绕组 500/525V — 列序【丙】
`D 星形(12线或6线)`；两列音压 `500V` / `525V`
→ 拆成 `9-500` / `9-525`，各只有 Y ✅

### 8.7 特殊22或23号绕组 550V — 列序【丙】
`D 星形` / 550V → 只有 Y ✅

### 8.8 特殊22或23号绕组 600V — 列序【丙】
`D 星形` / 600V → 只有 Y ✅

### 8.9 特殊10或52号绕组 660/690V — 列序【丙】
`D 星形(12线或6线)`；两列 `660V` / `690V`
→ 拆成 `10-660` / `52-690` ✅

### 8.10 标准6号绕组 单相230V
表头：`FF 双三角形(12线)` / `G 开式三角形(12线)`；电压 `220-240V`
本库 code `1ph-230` ✅（未细分）

### 8.11 单相M号绕组
表头：`单相绕组串联(4线)` 220-240V / `单相绕组并联(4线)` 110-120V
本库 code `1ph-230`（4线）

## 60Hz（第9章）

### 9.1 标准6号绕组 — 列序【甲】
`D 星形(12线或6线)` / `A 并联星形(12线)` / `F 三角形(12线或6线)`
电压：`380-416V` / `190-208V` / `220-240V`
→ D(380V)→A(190V)→F(220V)
本库 `6-380`(Y/Δ/YY) → 即 Y=380, Δ=220, YY=190 ✅

### 9.2 标准6号绕组 440/480V — 列序【乙】
`D 星形(12线或6线)` / `A 并联星形(12线)` / `F 三角形*(12线或6线)`
电压：`380-416V` / `190-208V` / `220-240V`（表尾行，但本节 kVA 标题是 220V,254V,440V / 240V,277V,480V）
→ **Y(440/480) → YY(220/240) → Δ(254/277)**
⚠️ 原库 `6-440`/`6-480` 写成 Y/Δ/YY，应为 Y/YY/Δ ❌

### 9.3 标准6号绕组(可选12出线) — 列序【甲】
同 9.1：D(380/416) → A(190/208) → F(220/240)

### 9.4 标准6号绕组(可选12出线) 440/480V — 列序【乙】
表尾：`D 星形` / `A 并联星形` / `F 三角形`
电压：`440-480V` / `220-240V` / `254-277V`
→ **Y(440/480) → YY(220/240) → Δ(254/277)**
⚠️ 原库 `6-12-440`/`6-12-480` 写成 Y/Δ/YY，应为 Y/YY/Δ ❌

### 9.5 特殊8号绕组 — 列序【乙】
`D 星形(12线或6线)` / `A 并联星形(12线)` / `F 三角形(12线或6线)`
电压：`380-416V` / `190-208V` / `220-240V`
→ **Y(380/416) → YY(190/208) → Δ(220/240)**
⚠️ 原库 `8-380`/`8-416` 写成 Y/Δ/YY，应为 Y/YY/Δ ❌

### 9.6 特殊9号绕组 — 列序【丙】
`D 星形(12线或6线)` 600V / `F 三角形(12线或6线)` 347V
本库 code `9-600`（只有Y/600V）；**缺 F/347V** ⚠️

### 9.7 特殊22或23号绕组 660/690V — 列序【丙】
`D 星形` 660V / 690V → `22-660` / `23-690` ✅

### 9.8 标准6号绕组 单相240V
本库 `1ph-240` ✅

### 9.9 单相M/M1号绕组
`单相绕组串联` 230-240V / `单相绕组并联` 115-120V
