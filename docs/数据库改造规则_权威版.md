# 数据库改造规则 · 权威版

> 来源：2026-09-21 与用户逐条确认（LSA / TAL / 斯坦福 三库改造定稿）
> **后续所有品牌库改造一律照此执行，不得自行发挥。**
> 用户原话：「后面的库我一个个给你喂，让你改，先记住这次三个新库的改造规则，后面都按这个来改造」

---

## 一、总原则（铁律）

1. **一切依据来自厂家手册原文**。不猜、不推、不类推别家。
2. **无数据就留空（省略键）**，绝不填 0，绝不脑补。
3. **手册空行必须保留**。
4. **核对/校验脚本必须独立于生成脚本**（同源自验 = 假阳性）。
5. **改前必备份**，命名 `xxx.json.bak_YYYYMMDD_HHMMSS_说明`，随时可回滚。
6. **一个库 = 一个品牌文件**。
7. **改完必须跑真实浏览器验证 + 回归**，通过了再推。

---

## 二、拆行规则

**每个独立维度组合 = 一行：**

```
型号 × 频率 × 绕组代码(winding_code) × 出线数(wires) × 接线(winding_conn) = 1 行
```

- 同一行的功率**按该接法自己的数值填**
- `winding_code` **保持原样不动**（前端选型依赖它）
- 例外：6 极机 `6P-` 前缀独立成档

## 三、字段规则（24 字段模板 + 本次新增）

### 基础字段
| 字段 | 说明 |
|---|---|
| `type` | 固定 `"generator"` |
| `brand` | 品牌名 |
| `model` | 型号 |
| `frequency` | `"50Hz"` / `"60Hz"` |
| `winding_code` | 电压-绕组键（前端匹配键，**不改**） |
| `winding_label` | 用户可读电压（**只留电压，接线挪走**） |
| `winding_conn` | **接线名（独立成列）** |
| **`phase`** | **★本次新增：`"1"`=单相 / `"3"`=三相（见第五节）** |
| `voltage` | 电压（单值如 `"380V"`，或范围如 `"380-440V"`） |
| `wires` | 出线数 |
| `pf` | 功率因数 |
| `exc_std` / `exc_opt` | 标准/可选励磁 |

**字段顺序：** `... winding_label → winding_conn → phase → voltage ...`
（`phase` 紧跟 `winding_conn` 之后）

### 功率字段（H/F 各 6 个，备用分温升）
`cont_h_kVA` / `cont_h_kW` / `stdby_h_40c_kVA` / `stdby_h_40c_kW` / `stdby_h_27c_kVA` / `stdby_h_27c_kW`
`cont_f_kVA` / `cont_f_kW` / `stdby_f_40c_kVA` / `stdby_f_40c_kW` / `stdby_f_27c_kVA` / `stdby_f_27c_kW`

## 五、★`phase` 字段判定规则（最易错，务必查手册原文）

**唯一依据 = 手册原文，判定顺序：**

1. **优先看「相 - 连接代码」行**
   - LSA/TAL 手册示例：
     ```
     相 - 连接代码  3 ph - D  3 ph - F  3 ph - D  3 ph - F  3 ph - A  1 ph - FF  1 ph - G
     连接           星形     三角形    串联星形   串联三角形   并联星形    双三角形   开式三角形
     ```
   - `3 ph` → `phase="3"`；`1 ph` → `phase="1"`

2. **若手册无该行，看章节标题**
   - 斯坦福示例：`4 POLE Single Phase` → 单相；`4 POLE Three Phase` → 三相

3. **⚠️ 绝不允许的判定方式：**
   - ❌ 靠接线名听起来像什么（「三角形」≠三相！`双三角形`/`开式三角形` 是单相）
   - ❌ 靠 pf 反推
   - ❌ 靠线数反推
   - ❌ 靠别家品牌类推

**已确认的判定表（LSA/TAL）：**
| 接线 | 相数 | 依据 |
|---|---|---|
| 星形 / Y | 三相 | `3 ph - D` |
| 三角形 / Δ | 三相 | `3 ph - F` |
| 串联星形 / YY | 三相 | `3 ph - D` |
| 串联三角形 | 三相 | `3 ph - F` |
| 并联星形 | 三相 | `3 ph - A` |
| **双三角形** | **单相** | **`1 ph - FF`** |
| **开式三角形** | **单相** | **`1 ph - G`** |
| 串联单相 | 单相 | M 绕组串联（4线） |
| 并联单相 | 单相 | M 绕组并联（4线） |

**斯坦福补充：**
| 接线 | 相数 | 依据 |
|---|---|---|
| 串联单相 / 并联单相 | 单相 | `4 POLE Single Phase`（Dedicated） |
| **串接三角形** | **单相** | **`4 POLE Single Phase`（Reconnectable）** |
| Y / YY / Δ | 三相 | `4 POLE Three Phase` |

## 六、前端联动规则

1. **前端直读 `phase` 字段**（`recPhase()`），**不在 JS 里硬编码接线名单**。
2. 旧库（无 `phase`）走兜底：label 含「单相」/ code 以 `1ph-` 开头 → 单相。**保证旧品牌不炸**。
3. 支持**范围电压档**（`380-440V`、`190V-208V`）：用户输入落点在区间内即命中，区间外报无匹配。
4. 表单顺序（用户定稿）：
   **品牌 → 频率 → 额定电压(手输) → 相数 → PF → 极数 → 接线方式 → ①主用功率 → ②备用功率 → 海拔 → 温度 → 特殊选配**
5. **相数与 PF 相互独立**（用户选方案 A）：切相数**不自动改 PF**。
6. PF 只写 `0.8` / `1.0`，**标签不带「三相/单相」字样**。

## 七、交付流程（每个品牌必走）

1. 读手册 → 摸清表结构（**PDF 手册解析按「题头块」切，不按「页」切**——一页可含多张表）
2. 生成新库 → `staging/conn_split/<品牌>/xxx.json`
3. **独立校验脚本**核对（物理校验 + 手册逐条核对 + 新旧库差异归类）
4. 加 `phase` 字段（按第五节规则）
5. **真实浏览器验证**（puppeteer + Chrome for Testing + `python3 -m http.server`，须在项目根启动）
6. **回归**：确认其他品牌不受影响
7. 备份原库 → 写入主库 → 提交 → **打锚点 tag/branch** → 推送

## 八、踩坑备忘（写死，别再犯）

- **PDF 手册解析不能按页切** → 按题头块切（`N POLE` / 频率行）
- **校验 key 不能用数值电压** → 必须用「手册电压原文 + 绕组号」（否则 380V 与 380V-416V 互相覆盖 → 假阳性）
- **报告出现大量「不符」→ 先怀疑解析/校验脚本，再怀疑库**
- **跨节同型号重名** → 索引必须带 `section`
- **电压格式归一化**（`220` vs `220V`）
- **`-` 占位导致整块错位** → 按 `-` 当槽位切块
- **出线正则别误命中励磁区**（`C6/4` 的 6）
- **型号名里的数字别当功率**
- **`lstrip('TAL-')` 是字符集剥离不是前缀剥离** → 用 `removeprefix`
- **前端改 JS 后必须 `node --check`**
