# 发电机组选型工具 · 用户操作逻辑梳理

> 目的：重新捋清「普通用户」从打开页面到拿到推荐型号的完整操作路径，
> 把「用户操作维度」与「内部匹配维度」分开，明确当前流程里哪些对用户是负担、逻辑哪里值得改。
>
> 核心用户心智（用户原话）：
> **选择品牌 → 选择频率 → 选择电压 → 选择功率 → 选择海拔 → 选择温度**
> 绕组对于普通用户难以理解。

---

## 一、当前操作流程（现状，按用户可见顺序）

### 表单控件顺序（index.html 172-189 行）
1. **电机品牌**（genBrand，下拉）
2. **额定电压（接线方式）**（genWinding，下拉）← 注意：标题就叫「接线方式」
3. **频率**（genFreq，50Hz/60Hz 单选）
4. **工作制**（genDuty，主用 PRP / 备用 ESP 单选）
5. **额定功率**（genPower，数字输入，默认100）
6. **安装海拔**（genAlt，数字，默认0）
7. **环境温度**（genTemp，数字，默认40）
8. **功率因数 PF**（genPF，下拉 0.8/0.85/0.9/1.0）

### 用户实际填写顺序
页面从上到下：**品牌 → 电压 → 频率 → 工作制 → 功率 → 海拔 → 温度 → PF**

> ⚠️ 用户期望顺序是「品牌→频率→电压」，
> 但页面控件是「品牌→**电压**→频率」——电压下拉的可用性依赖已选频率，
> 实际交互是：先选品牌 → 电压下拉显示「请先选择品牌和频率」→ 再切频率 → 电压才有选项。
> **顺序上有轻微断层**（用户要先知道频率，但频率控件在电压下方）。

## 三、关键逻辑事实（已从代码确认）

1. **接线（winding_conn）在选型里是纯展示**，不参与过滤/匹配。
   只出现在：① 电压下拉选项文案（`label+（接线）`）；② 产品库表格。
   真正决定匹配的是 `winding_code`。

2. **绕组（winding_id / 中高压绕组号）是内部维度**。
   - 中高压：已实现「电压等级分组 + 绕组并入选型内部匹配」（方案1）
   - 低压：**同一电压下多绕组（如斯坦福 S9L1D-C 的 13/14/613 与 311/312/12）
     因 winding_code 相同无法区分，会在结果里出现「同型号一个✅一个❌」**——此问题已发现，暂未处理（见记忆）。

3. **温升等级（H/F）是中高压内部选型基准**（中高压按 F 级温升选型）。
   利莱森玛中高压无 cont_f 列、回退 cont_h 已修复。

4. **当前匹配链路**：频率过滤 → 电压(winding_code)过滤 → 读主用/备用电功率 →
   海拔/温度修正 → 与目标比较 → 排序 → 推荐最优。**接线、绕组、温升都不在用户选择维度里**（除了展示）。

## 四、用户操作逻辑的「理想简化」方向（待讨论）

### 目标
**让用户只做 6 件事**：品牌 → 频率 → 电压 → 功率 → 海拔 → 温度。
所有「接线、绕组、线数、温升、多电压段」尽量下沉为内部匹配，结果里再说明。

### 具体建议（分层）
1. **接线保留但弱化**：用户能理解接线 → 可保留在电压下拉，但建议把
   「Δ/Y、YY,Δ/Y、星形/三角形、12线」这类**串在一起的长文本**精简为
   「括号内简短接线」，如 `380V（Δ/Y）`，去掉冗余（如「双三角形+开式三角形(12线)」太冗长）。

2. **电压下拉只表达「电压 + 单相/三相 + 简短接线」**，不把多个电压段硬拼成
   一个选项（美奥迪 `220/380/440/760V`、马拉松 `190/220V+380V` 这种应拆开）。

3. **绕组/多绕组**：低压的「同电压多绕组」问题，按中高压方案1思路——
   下拉屏蔽绕组，选型内部遍历所有绕组取最优；结果里附绕组号解释。

4. **英文术语本土化**：Reconnectable/Dedicated/Star/Delta/W11 等 → 中文
   （可恢复/专用/星形/三角形/绕组），降低阅读门槛。

### 需要你拍板的点
- A. 电压下拉到底保留到什么粒度？（简化到「电压+接线」，还是保留多电压段？）
- B. 低压「同电压多绕组」（斯坦福 S9L1D 那类）怎么处理？参照中高压方案1还是别的？
- C. 英文术语是否全部中文化？
- D. 表单控件顺序是否调整（频率提前到电压之前，符合用户心智）？

## 五、附带发现（与本次梳理相关）

1. 表单「额定电压（接线方式）」标题已把接线当主信息——与「用户只关心电压」略冲突，可考虑改标题为「额定电压」。
2. 页面控件顺序与用户心智顺序不一致（见第一节）。
3. 「功率单位 kW/kVA」切换、单相/三相的 PF 拆分逻辑较复杂，普通用户可能困惑（待确认是否纳入本次范围）。
