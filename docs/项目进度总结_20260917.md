## 二、核心修复：卡片「备用27℃」串位（commit 921a793）

### 现象
低压 ESP40（40℃ 备用）模式选型时，最佳匹配卡片的「备用27℃」显示成了 40℃ 的值。

```
ESP40 模式（利莱森玛 LSA 6-400，50Hz，300kVA）
  修复前:  备用40℃: 318 | 备用27℃: 318   ← 串位
  修复后:  备用40℃: 318 | 备用27℃: 330   ✅ 正确
```

### 根因
`doSearch()` 生成候选列表时，卡片展示字段 `s27` 与「当前选中温升列」`standbyCol` 写成了同源：

```js
// 错误写法
s27: g[standbyCol + '_' + uKey]   // 40℃模式下 standbyCol = stdby_h_40c
```

40℃ 模式下 `standbyCol` 指向 `stdby_h_40c`，导致 `s27` 读到的也是 40℃ 的值。
**这是同一类 bug 的第二次出现：一个变量承载两种语义（随模式变的 / 固定不变的）。**

### 修复
把「卡片固定展示值」与「参与计算和排序的值」彻底分离：

```js
// 卡片展示用固定值：与 st（当前选中温升备用值，参与计算/排序）分离
var s27v = isHV
  ? ((g['stdby_f_27c_'+uKey] > 0) ? g['stdby_f_27c_'+uKey] : g['stdby_h_27c_'+uKey])
  : g['stdby_h_27c_'+uKey];

list.push({
  ...,
  s40: g['stdby_h_40c_'+uKey],   // 固定 40℃ 备用
  s27: s27v,                      // 固定 27℃ 备用
  st:  g[standbyCol+'_'+uKey],    // 当前选中温升（仅在算法内部使用）
  ...
});
```

- **低压**：27℃ 固定取 `stdby_h_27c`（H 级）
- **中高压**：27℃ 取 `stdby_f_27c` 优先，无则回退 `stdby_h_27c`
- **40℃**：固定取 `stdby_h_40c`（低压 40℃ 备用按用户要求使用 H 级）

## 五、⚠️ 本轮挖出的 4 个问题（全部是验证脚本自身的，前端无误）

| # | 现象 | 根因 | 修正 |
|---|---|---|---|
| B1 | 中高压报 50 例失败 | 中高压遇到 ESP40 会**回退成 ESP**，脚本按原工作制选列 | 先算 `dutyEff`，再选列 |
| B2 | 报 22 例「卡片无值但应有值」 | 合法值集合取了**跨型号候选集**；斯坦福有 199 组重复三元组 | 只跟「最佳型号自己那一行」比对 |
| B3 | 遗留 5 例差 0.2~3.6 | **Python `round()` 是银行家舍入，JS `Math.round()` 是四舍五入** | 自写 `jround()` 对齐 JS |
| B4 | 报 1 例「串位」（斯坦福 S0L1-D） | 该型号同绕组有 2 条记录，其中一条本身 27℃==40℃，显示相同是正确的 | 串位判定改为按「同一条记录」判断 |

### 🔑 跨语言舍入差异（重点）
`Python round()` = 银行家舍入（0.5 向偶数）；`JS Math.round()` = 四舍五入（0.5 进位）。
例：`0.97 × 1.05 = 1.0185` → JS 得 `1.019`，Python 得 `1.018`。
**凡校验前端计算值，必须用 JS 等价实现**，否则会涌现一批 0.2~3.6 的假失败。

### 🔑 验证设计五条铁律
1. 验证脚本必须**复用前端真实系数表**（从 index.html 抽取），不得硬编码近似值
2. 卡片值校验必须**限定在最佳型号自己那一行**（重复三元组品牌尤其重要）
3. 工作制回退逻辑（中高压 ESP40→ESP）必须在**校验侧同步实现**
4. 舍入方式必须**对齐 JS**
5. **每一个模式、每一条分支都要覆盖** —— 上一版校验只在 27℃ 模式跑，40℃ 分支被跳过，正好漏掉了出问题的那条路径

## 六、⭐ 最重要的一条教训

> **「当前选中维度」的变量，绝不能复用于「固定展示值」。一变量双语义 = 必出串位。**

`standbyCol` 这类变量会随用户选择变化（27℃ / 40℃），而卡片上的「备用27℃」和「备用40℃」
是两个**固定列**。两者混用，就是这次 bug 的根源。

**自检方法**：写 `list.push` 时逐字段自问 ——
「这个值会随用户选择变化吗？」
- **会变** → 用 `standbyCol`
- **不变** → 写死列名

同时，这类 bug 已出现两次（最早的中高压卡片、这次的 40℃ 模式），说明校验设计必须
**覆盖所有分支**，不能只测「默认路径」。
