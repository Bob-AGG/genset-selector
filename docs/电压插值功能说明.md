# 电压两点插值功能说明（利莱森玛 LSA 60Hz 380~416V）

> 建立日期：2026-11-03
> 适用文件：`genset-selector/index.html`（前端单文件）
> 对应提交：`58d478c feat(selection): 利莱森玛LSA 60Hz 三相Y 6/6-12/8号绕组 380~416V 电压两点插值`

---

## 一、为什么要做这个功能

**问题**：利莱森玛 LSA 在 60Hz、三相、Y（星型）接法下，手册数据表只给出 **380V** 和 **416V** 两个电压点的功率。用户在 60Hz 项目上实际用的是 **400V**（或 390、405 等），网页上输入 400V 直接提示「无匹配」，选不了型。

**原理**：标准 6 号绕组 Y 接法的实际可用电压范围就是 **380~416V**，400V 完全在这个范围内，只是手册没单独列一行。既然电压和功率近似线性关系，可以用两端点插值算出 400V 的功率。

**解决**：用户输入 380~416 之间任意电压，系统自动按两端点线性插值估算功率，并在结果中标注「估算」。

## 二、怎么用（用户操作）

### 正常操作流程（和以前一样）

1. 打开 https://bob-agg.github.io/genset-selector/
2. **品牌**选「利莱森玛 LSA」
3. **频率**选 **60Hz**
4. **额定电压**输入 **400**（或 390、405 等 380~416 之间的任意值）
5. 接线下拉会自动出现「**Y · 400V**」，提示「✅ 400V 命中 1 种接线方式、96 个绕组档」
6. 选好接线
7. 填功率（主用 / 备用，至少填一个）
8. 点搜索

### 怎么看出这是估算值

- 推荐卡片型号后面有 **`*`** 号，如「LSA 44.3 M6\*」
- 候选表型号列也带 **`*`** 号
- 鼠标悬停在 `*` 上会提示「该电压档为 380/416V 两点插值估算」

**没有 `*` 号的都是手册原值**，可以放心当作准确数据用。

### 什么时候会有 `*`

| 输入电压 | 结果 |
|---|---|
| 380V | 原值，无 `*` |
| 416V | 原值，无 `*` |
| 381~415V（如 400） | **插值估算，带 `*`** |
| 370V / 420V | 无匹配（不外推） |
| 440V / 480V | 原值，无 `*`（其他绕组抽头） |

## 三、计算规则（技术口径）

### 公式

```
P(V) = P380 + (V - 380) ÷ 36 × (P416 - P380)
```

其中 `36 = 416 - 380`。

### 举例：LSA 44.3 S3，6 号绕组，400V

| 项目 | 380V 原值 | 416V 原值 | 400V 插值 |
|---|---|---|---|
| 持续 H 级 kVA | 79.0 | 87.0 | 79 + (20/36)×8 = **83.4** |
| 持续 H 级 kW | 63.2 | 69.6 | 63.2 + (20/36)×6.4 = **66.8** |

> 手算验证：20/36 = 0.5556，×8 = 4.444，79 + 4.444 = 83.44 → 四舍五入 83.4 ✓

### 12 个功率字段全部独立插值

kVA 和 kW **各自单独插值**，不用 kVA 结果反推 kW（因为各口径 PF 可能不同）。

- `cont_h_kVA` / `cont_h_kW`（H 级持续）
- `stdby_h_40c_kVA` / `stdby_h_40c_kW`（H 级备用 40℃）
- `stdby_h_27c_kVA` / `stdby_h_27c_kW`（H 级备用 27℃）
- `cont_f_kVA` / `cont_f_kW`（F 级持续）
- `stdby_f_40c_kVA` / `stdby_f_40c_kW`（F 级备用 40℃）
- `stdby_f_27c_kVA` / `stdby_f_27c_kW`（F 级备用 27℃）

### 触发条件（必须全部满足）

1. 品牌 = `leroysomer`（利莱森玛 LSA 低压）
2. 频率 = `60Hz`
3. 相数 = 三相（`phase == 3`）
4. 接线 = `Y`（星型）
5. 绕组 code 属于：`6-380/6-416/6-440/6-480`、`6-12-380/6-12-416/6-12-440/6-12-480`、`8-380/8-416`
6. 用户电压 **严格在 380 与 416 之间**（不含端点）
7. PF = 0.8（三相口径）

**任一条不满足 → 不插值**，保持原有行为。

### 不适用的情况（保持原样）

- 50Hz（原表已有 380/400/415V，直接取原值）
- Δ 接线、YY 接线（这些是另外的电压档，不能用 380/416 插值）
- 单相（1ph）
- 其他品牌（斯坦福、AGG、美奥迪、马拉松、英格、铨一、订高、TAL、中高压等）
- 9 号 / 22 号 / 23 号等其他绕组
- 440V / 480V / 600V / 660V / 690V（其他绕组抽头，严禁用 400÷440 反推）

### 位置 2：三个核心函数（第 1227~1310 行）

| 函数 | 作用 | 什么时候改 |
|---|---|---|
| `interpWindingBase(code)` | winding_code → 绕组基座（`6`/`6-12`/`8`） | 加新绕组类型时 |
| `recInInterpScope(r)` | 判断一条记录是否属于插值范围 | **改触发条件时（最常改）** |
| `buildInterpRecords(brand,freq,volt,pf)` | 生成插值临时记录 | 改公式或字段时 |

**最常改的是 `recInInterpScope()`**，判断条件都写在这里：

```js
function recInInterpScope(r){
  if(!r) return false;
  if(String(r.brand||'').trim()!=='leroysomer') return false;   // ← 品牌
  if(String(r.frequency||'').trim()!=='60Hz') return false;     // ← 频率
  var ph=(r.phase==null?'3':String(r.phase).trim());
  if(ph!=='3' && ph!=='三相' && ph!=='3ph') return false;        // ← 相数
  if(String(r.winding_conn||'').trim()!=='Y') return false;      // ← 接线
  if(interpWindingBase(r.winding_code)===null) return false;     // ← 绕组
  var vs=String(r.voltage||'').trim();
  return vs==='380V' || vs==='416V';                             // ← 端点电压
}
```

**例：以后要让某些品牌也能插值** → 把品牌判断改成白名单：
```js
if(['leroysomer','stanford'].indexOf(String(r.brand||'').trim())<0) return false;
```

### 位置 3：`findVoltMatches()` 末尾的回退（第 1329 行附近）

```js
  // ★精确匹配为空时，回退到 380/416 两点插值（仅利莱森玛LSA 60Hz 三相 Y 6/6-12/8号绕组）
  if(hits.length===0){
```

**作用**：用户输入 400V 时，接线下拉能正常出现「Y · 400V」。没有这段，用户连接线都选不了，根本走不到搜索。

## 五、插值记录的字段结构

生成的临时记录是**复制 380V 那条记录**再改电压和功率，所以 label、接线、出线数、PF 等字段都沿用原值：

```js
{
  ...380V原记录的所有字段,
  voltage: "400V",              // 改写
  winding_label: "400V",        // 改写
  estimated: true,              // ★新增标记
  interp_from: "380V/416V",     // 来源说明
  interp_base: "6",             // 绕组基座
  source_model: "LSA 44.3 S3",  // 原型号
  cont_h_kVA: 83.4,             // 插值结果
  cont_h_kW: 66.8,              // 插值结果
  ...其他 10 个功率字段
}
```

> `winding_code` **保持原样**（如 `6-380`），因为前端筛选依赖它。

**特殊说明**：12 线变体（`6-12-*`）插值后 `winding_code` 仍是 `6-12-380`，这样能被 12 线出线的筛选正常识别。

## 八、注意事项 / 踩坑备忘

1. **`INTERP_BASES` 顺序不能乱** —— `'6-12'` 必须在 `'6'` 前面。否则 `'6-12-380'` 会被 `'6'` 抢先匹配成 6 号绕组，导致 12 线变体和普通 6 号混在一起算。

2. **端点电压用字符串比对** —— 判断 `vs==='380V'`，因为库里电压字段是字符串。别改成数字比对。

3. **`if(hits.length===0)` 不能删** —— 这是保证精确匹配优先的关键。删了会导致 50Hz 400V（本来有原值）也混进插值记录。

4. **kVA 和 kW 必须各自插值** —— 不能先插 kVA 再乘 0.8 得 kW。个别机型不同口径 PF 不完全一致，各算各的才准。

5. **插值记录是临时生成、不写数据库** —— 每次搜索现算，不改 json 数据文件。所以数据库永远保持手册原值。

6. **浏览器缓存** —— 改完推送后用户看到的可能还是旧版，让用户 `Cmd+Shift+R` 强制刷新。

7. **后端不受影响** —— 后端 `backend/selection.py` 本轮**未部署**到服务器，线上 AI 对话仍是旧行为。如需 AI 也支持，需要另外同步服务器。

## 九、相关数据事实（备查）

**60Hz 三相 Y 接法下 LSA 的电压档**：
`380 / 416 / 440 / 480 / 600 / 660 / 690 V`

**有 380+416 两档的「型号+绕组」组合**：115 个
- 其中 104 个可插值（两端都有数据）
- 11 个两端都没有（如 LSA 46.3 L10 的 8 号绕组），不参与插值

**两档功率相同的机型**（插值结果 = 该值，属正常）：
- 8 号绕组：LSA 42.3 VS1/VS2/VS3、LSA 50.2 L7、LSA 50.2 M6、LSA 52.3 L12/L9/S6/S7、LSA 53.2 M12/M9
- 共 11 个

> 这类机型用「单端系数法」（400÷416 或 400÷380）会算出明显偏离的值（如 LSA 52.3 L12 实测 3000 kVA，单端法算 2884 或 3158），只有两点插值才能得到正确结果 —— 这也是当初选插值法而非系数法的原因。

**只有 380V 没有 416V 的特例**：
- LSA 50.2 L8 的 `6-12-` 12 线变体 → 无法插值，属正常
